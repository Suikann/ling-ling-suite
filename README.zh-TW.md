# 泠靈小工具

**專為樂團譜務設計的模板化分譜管理系統。**

[English](README.md) | [繁體中文](README.zh-TW.md)

## 專案簡介

**泠靈小工具**是一套桌面應用程式，旨在解決樂團譜務人員在處理分譜檔案時的命名、分割與整理需求。提供視覺化的 PDF 分割與旋轉、模板化批次重新命名、以及專案化的檔案管理工作流。

## 核心功能

### 模板化重新命名
使用變數語法自訂檔名格式：
- **範例：**`{序號}-{曲名}-{樂器}.pdf` 產生 `01-貝多芬第五號交響曲-Flute.pdf`
- **群組覆寫：**每個群組可使用自訂格式，完全取代命名格式

### 視覺化 PDF 分割
以縮圖介面將合譜 PDF 拆分為各樂器的獨立分譜：
- 點擊頁面縮圖標記分割點
- 色彩分區顯示，搭配樂器名稱指派
- 右鍵或雙擊放大預覽

### PDF 旋轉
依區段設定不同旋轉角度：
- 標記旋轉段落邊界（類似分割點）
- 每個段落獨立選擇角度（0/90/180/270 度）
- 覆寫前自動備份，支援復原

### 預設編制表
內建常見樂團編制：
- 管弦樂團、管樂團、弦樂團
- 國樂合奏、絲竹室內樂
- 每個群組擁有獨立的樂器表

### 專案管理
- 儲存/載入專案檔（`.llproj`），保留所有設定
- 最近開啟的專案快速存取
- 每群組可指定總譜檔案（序號為 00）
- 依群組建立分譜資料夾

### 復原/重做
- 支援重新命名、分割、旋轉操作的復原
- 重新命名支援重做（Ctrl+Z / Ctrl+Y）
- PDF 旋轉覆寫前自動備份

### 雙語支援
- 繁體中文與英文即時切換，無需重啟
- 模板變數名稱自動轉換（序號/Number、樂器/Instrument 等）

## 下載

前往 **[Releases](../../releases)** 頁面下載最新版本。免安裝，解壓即可使用。

## 快速開始

1. 啟動 `LingLingSuite.exe`
2. 透過**匯入**選單加入 PDF 檔案或資料夾
3. 在左側面板**設定樂器表**（手動輸入或載入預設編制）
4. **建立群組**，每個群組代表一首曲目的一個樂章
5. 在底部**設定命名格式**（如 `{序號}-{曲名}-{樂器}.pdf`）
6. 點擊**預覽並重新命名**執行

## 開發者指南

**環境需求：**
- Python 3.11+
- PySide6、PyPDF2、PyMuPDF、send2trash

**從原始碼執行：**
```bash
git clone https://github.com/Suikann/ling-ling-suite.git
cd ling-ling-suite
pip install -r requirements.txt
python src/main.py
```

**執行測試：**
```bash
pip install pytest pytest-cov
python -m pytest tests/ -v
```

**打包為可攜式 EXE：**
```bash
build.bat
```

## CI/CD

- **CI：**每次 push/PR 自動執行測試（Python 3.11 + 3.12，Windows）
- **CD：**推送 `v*` 標籤自動打包可攜式 EXE 並建立 GitHub Release
