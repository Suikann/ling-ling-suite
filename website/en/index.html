Ling Ling Suite

A PDF management tool for orchestra music librarians.

Ling Ling Suite (泠靈小工具) is a desktop program that runs on your own computer. It is free and open source (MIT license) and runs on Windows and Linux. Music librarians use it to:

  • Split the combined PDFs delivered by publishers or notation software into a score and parts using page thumbnails, and rotate pages by section
  • Order parts by an instrument list and batch rename them with a naming template such as {Number}-{PieceName}-{Instrument}.pdf, with undo and redo
  • Compress oversized scanned parts below 20MB, comparing each file before it is written out
  • Connect to the club's catalog (a Google spreadsheet plus Drive) to manage instrumentation, headcounts and durations, and archive parts to the catalog
  • Distribute parts to HuaXia, the website of the HuaXia Chinese Orchestra Club, where members pick them up

Privacy

Ling Ling Suite has no server and contains no ads, tracking or usage statistics. Google data travels only between your computer and your Google account; only when an officer distributes, retracts or recalls does Ling Ling write or delete data on the club's HuaXia, directly from your computer. Sign-in tokens are kept in the operating system's secure storage. See the Privacy Policy.

Source code and issues

The source code is on GitHub. Please report problems or suggestions on GitHub Issues.
