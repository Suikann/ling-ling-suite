分割模組
與候選 1 對稱：模組回傳結果與紀錄，UI 只顯示。復原分割能更新群組引用。
Problem

分割對磁碟與專案的全部效果分散在對話框與主視窗，中間以六個位置參數回呼；呼叫端必須知道「工作區模式才清舊輸出」「replaced 只在工作區模式有值」「source_group 為 None 代表新建群組」。test_split_dialog 得設私有欄位才碰得到 _build_split_plan。

Solution

一個分割模組收來源、計畫、目的地、專案；自己做預檢（回傳會被取代的分譜與所屬專案）、清舊輸出、準備工作區資料夾、擷取、套用到專案、產出復原紀錄；對話框只收集分割點與名稱。

Wins
  • locality：分割的效果集中一處
  • 六參數回呼消失
  • 中途失敗的回滾有地方放
  • 復原分割可更新群組引用
  • 空白 PDF＋暫存目錄即可測，不需 Qt
不牴觸 ADR-0001；反而讓「分割輸出進工作區、匯入檔不動」這條規則有可直接測的落點。
