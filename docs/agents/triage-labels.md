# Triage 標籤

skill 以五個標準 triage 角色溝通。本檔把角色對映到本 repo 實際使用的標籤字串。

| mattpocock/skills 角色 | 本 repo 標籤 | 意義 |
| --- | --- | --- |
| `needs-triage`    | `待分類` | 維護者待評估此 issue（只給外部進來的 issue） |
| `needs-info`      | `待補資訊` | 等回報者補更多資訊 |
| `ready-for-agent` | `待派工` | 完整規格、agent 可接（你自己開 session 跑 `/implement`；沒有東西會自動撿） |
| `ready-for-human` | `待人工` | 需人工實作 |
| `wontfix`         | `不處理` | 不予處理 |

當 skill 提到某角色（如「apply the AFK-ready triage label」），用本表對應的標籤字串。右欄可隨實際詞彙調整。
