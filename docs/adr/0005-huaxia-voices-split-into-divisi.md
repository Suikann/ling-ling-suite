# HuaXia 的聲部可以分成分部

HuaXia 曲目上的聲部（`piece_parts`）多半是從既有試算表匯入的排人單位，比樂譜細：一份二胡分譜在 HuaXia 上是二胡 I、二胡 II，一份擊樂 2 是風鈴、鈴鼓等一件樂器一格。泠靈一個聲部只能對一個 HuaXia 聲部，115-1 發譜只好在本機把分譜複製成每格一份；HuaXia 網頁上的編制也被切得太細，看不出整個聲部的人夠不夠。我們決定在 HuaXia 加一層：聲部（對應一份分譜）底下可以有分部（排人的單位），只分兩層。分出分部的聲部，樂譜只掛在聲部上、排人只排在分部，分部的團員讀得到所屬聲部的分譜。

## Considered Options

- **只改泠靈，一個聲部對多個 HuaXia 聲部，每格各傳一份**：不必改 HuaXia、不必送合併請求，Storage 的重複也會被收回清掉；但 HuaXia 網頁的編制仍然平鋪、看不出分層，而 HuaXia 那邊的幹部同樣需要這一層。
- **HuaXia 加一張表，記一筆樂譜給哪些聲部看**：Storage 只存一份、聲部結構不動；同樣解決不了網頁上平鋪的編制。

## Consequences

- **人數兩層各記、不加總**：聲部的人數是確認過的總人數，泠靈照舊寫入；分部各有自己的人數，泠靈不動。打擊是一人負責好幾件樂器、同一人排在好幾個分部，所以分部的人數加總不等於聲部的人數。缺人兩層都判斷：分部看自己的人數，聲部看所有分部排到幾個不同的人。
- **聲部組跟著聲部**：分部不另記聲部組。
- **歸分部兩邊都能做**：幹部在 HuaXia 網頁上設定，譜務也能在發譜時把現有的 HuaXia 聲部歸到泠靈的聲部底下（經發譜函式）。
- **要對 HuaXia 送合併請求，發譜函式的版本加一**：照 ADR 0003 的方式送；版本加一後，舊版泠靈停用發譜（`docs/huaxia/LINGLING.md`「改了會影響泠靈的事」）。
